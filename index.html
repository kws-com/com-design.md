02

Core Typography↘

Rendered at 1:1 scale. Geist is used exclusively for h1, body text, and the lower CTA label. Geist Mono is used for everything else, set in uppercase.

Click any mark to copy clean, Figma-ready SVG XML code. The primary lockup is visually larger for primary brand attribution, while standalone marks live inside square frames.
